
# DriverNet AI — End-to-End Autonomous Driving System


DriverNet AI is a deep learning and computer vision project that explores end-to-end autonomous vehicle control by learning steering behavior directly from road images. Instead of relying on manually defined driving rules, the system learns driving patterns from recorded human driving data and predicts continuous steering commands using a convolutional neural network.


The project combines a PyTorch-based deep learning model, an image preprocessing pipeline, training visualization, and an interactive browser-based driving simulator to demonstrate how visual information can be transformed into vehicle control decisions.


## Overview


DriverNet AI follows an end-to-end learning approach in which road images are processed by a deep neural network to predict the appropriate steering command.


```text
Driving Image
      ↓
Image Preprocessing
      ↓
Convolutional Neural Network
      ↓
Visual Feature Extraction
      ↓
Steering Prediction
      ↓
Driving Simulation

The model receives a road image as input and produces a continuous steering angle as output.

Key Features
End-to-End Steering Prediction

The system learns the relationship between road images and steering behavior from recorded human driving data. A custom CNN implemented with PyTorch predicts steering commands directly from visual input.

Computer Vision Pipeline

The project includes an image preprocessing pipeline designed to improve model robustness across different driving scenarios.

The preprocessing stages include:

Region-of-interest extraction
Image resizing
Color-space transformation
Brightness variation
Spatial shifting
Image normalization
Deep Learning-Based Steering Control

DriverNet AI uses a convolutional neural network to learn important visual patterns such as:

Road structure
Lane patterns
Road curvature
Driving cues
Visual features relevant to steering decisions

The model performs continuous regression to generate steering-angle predictions.

Interactive Driving Simulation

A browser-based simulator provides an interactive way to observe the model's steering behavior.

Users can modify road curvature and driving conditions and observe how the predicted steering response changes.

Training Visualization

The project includes visualization capabilities for monitoring the training process, including:

Training progress
Loss reduction
Optimizer behavior
Learning trends
Behavioral Cloning

DriverNet AI demonstrates the concept of behavioral cloning, where a neural network learns driving behavior from examples generated by a human driver.

The overall learning process is:

Human Driving Data
        ↓
Road Images + Steering Commands
        ↓
Image Preprocessing
        ↓
CNN Training
        ↓
Learned Driving Behavior
        ↓
Predicted Steering Command

Instead of manually programming steering rules, the model learns the relationship between visual road conditions and steering decisions from the training data.

Model Architecture

The network accepts an RGB image with dimensions:

66 × 200 × 3

The convolutional architecture consists of:

Input Image
66 × 200 × 3
        ↓

ELU
        ↓
Convolution Layer

        ↓
ELU
        ↓
Convolution Layer

64 filters, 3×3 kernel

        ↓

The final output represents the predicted steering angle.

Running the Project

The interactive simulation can be launched without installing the machine learning dependencies.

Clone the Repository
git clone https://github.com/archana117/DriverNet-AI-Autonomous-Driving-System.git
cd DriverNet-AI-Autonomous-Driving-System
Start a Local Web Server
python -m http.server 8000
Open the Application

Open the following address in your browser:

http://localhost:8000

The browser-based simulation interface will then be available locally.

Deployment

The simulation interface is structured as a lightweight web application and can be deployed using Vercel.

npx vercel --prod

The application can also be deployed using other platforms that support static web applications.

Objective

The objective of DriverNet AI is to demonstrate how computer vision and deep learning can be combined to learn vehicle steering behavior directly from visual road information.

The project provides a practical example of behavioral cloning and end-to-end autonomous vehicle control, connecting visual perception with continuous steering prediction through an interactive simulation environment.
